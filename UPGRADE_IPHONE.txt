KRAKEN MEME SIGNAL RADAR — V3 — IPHONE UPGRADE

1. Download Kraken_Signal_Radar_V3.zip to your iPhone and tap the ZIP in Files → Downloads to unzip.
2. In Safari, open your EXISTING repo:
   https://github.com/declanreilly0/kraken-signal-ai
3. Tap Add file → Upload files. If hidden, use Safari's Request Desktop Website.
4. Upload these files from the unzipped V3 folder to the MAIN repository folder:

   app.py
   radar.py
   discovery.py
   engine.py
   kraken_api.py
   chart_ui.py
   requirements.txt
   README.md
   (optional UPGRADE_IPHONE.txt)

   The files must be INSIDE the repo, NOT a ZIP and NOT nested under another folder.
   Replacing app.py, engine.py, requirements.txt and the others is intentional.
5. Tap Commit changes → Commit directly to main.
6. Open your EXISTING Streamlit website. Let it redeploy and reload Safari.
7. You should see "KRAKEN · SIGNAL RADAR / V3".
8. On Best setups, read the first 8 deeply scanned candidates. Tap Scan next batch
   to check more, or enable auto-scan in the sidebar WHILE THE APP IS OPEN.
9. Select Meme-first (all coins), then inspect conditional buy/target/stop/profit cards.
   Click "Open [coin] chart" to see candles. A WAIT/SKIP is NOT an invitation to trade.

If it fails: Streamlit → Manage app → Logs. Send a screenshot of the ERROR TEXT.
Do not post Kraken passwords or private API keys in GitHub or screenshots.

IMPORTANT: A first-pass snapshot covers Kraken online spot pairs, but only some
are deeply analysed per batch. Newly discovered does not equal newly listed.
New Solana meme coins not listed on Kraken are NOT available in this app.
The app is research-only, with no Kraken account access or auto-execution.
